# fxhashViewer (moved)

This repository is a signpost, not a project. The archive it used to hold was
renamed to **[fxhashArchive](https://github.com/KilledByAPixel/fxhashArchive)**
and now lives at
**[killedbyapixel.github.io/fxhashArchive](https://killedbyapixel.github.io/fxhashArchive/)**.

GitHub redirects a renamed repository everywhere *except* its GitHub Pages site,
so this repo exists to keep every link anyone has already shared working. It
carries the path and the `#` fragment across, which means deep links survive too:

```
killedbyapixel.github.io/fxhashViewer/#/token/some-slug
  -> killedbyapixel.github.io/fxhashArchive/#/token/some-slug
```

## Setup

Settings → Pages → Deploy from a branch → `master` / `/ (root)`.

Nothing else belongs here. Do not add code to this repository.
